# Clip-04 v18 — Sound note

Rule giữ nguyên: file video **không có nhạc** (luật 21); trong file chỉ có giọng F5 + SFX (`swish`, `tick`, `rise`, `pop`, `pen`, `ding`) + `ambience`. Nhạc do Hiệp thêm trong app TikTok lúc đăng, **chỉ từ Commercial Music Library** (Sounds → Commercial Sounds).
File này không sửa script đã khoá, không sửa `post.md` / `publish/post-package.md`.
