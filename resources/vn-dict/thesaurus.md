# Kho từ sắc (rule 58, DL-059)
Từ nhạt → từ cụ thể, có hình ảnh. Mọi từ ghép đã tra trong `Viet74K.txt` (73.901 mục, github.com/duyet/vietnamese-wordlist). Tra nhanh: `python3 pipeline/scripts/vn-words.py "<câu>"`.

| Nhạt / mơ hồ | Sắc hơn (chọn theo ngữ cảnh) |
|---|---|
| X thắng (điện thoại thắng) | tay chộp TikTok · ngón cái tự lướt · bị cuốn vào |
| chán | chán ngán · ngán ngẩm · uể oải |
| sợ làm dở | sợ hỏng · ngại sai · run tay |
| không biết bắt đầu | rối · mù mờ · ngợp |
| việc càng khó chịu (lặp) | nặng nề · trĩu · nhức đầu |
| ở xa / ở ngay bây giờ | tận cuối tháng · ập tới ngay · sát nút |
| hoãn | dời · khất · lần lữa · để mai |
| tự mắng | dằn vặt · tự trách · tự xỉ vả |
| tội lỗi | day dứt · cắn rứt |
| một cảm giác | cảm giác khó chịu (gọi tên rõ) |
| làm (chung chung) | gõ · viết · mở file · bấm chạy |
